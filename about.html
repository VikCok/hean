ABOUT · HEAN

站点简介

HEAN 禾安（hean.me）是一个个人站点，也是一块属于自己的网络空间。它从一个简单的聚合搜索页出发，逐步生长出游戏工具、兴趣聚合、每日资讯等分区，记录学习、体验与生活的碎片。本站追求极简、快速、无广告的浏览体验，所有功能均为个人兴趣驱动。

这里有什么

  • 聚合搜索：首页集成了 Bing、百度、Google、网易云音乐四个搜索引擎，一键切换、即搜即走。
  • 每日一言：首页展示中英双语励志文案，每次刷新获取新内容。
  • 趣味板块：每日塔罗牌、今日运势、MBTI 人格、每日一签，均为点击触发，娱乐性质。
  • 资讯聚合：GitHub 热榜、AI 科技新闻、每日热点新闻、人民日报金句，一站式浏览。
  • 游戏工具：光遇助手（老奶奶干饭时钟、今日任务、活动日历、季节倒计时等）、CS2 工具箱（箱子刷新倒计时）。
  • 生活工具：今日黄历、王者荣耀英雄随机、喜加一限免游戏追踪。
  • 主题切换：顶栏提供暗黑 / 白色双主题，记忆用户偏好，切换页面不闪白。

光遇助手

光遇助手是本站的特色功能页面，为《光·遇》玩家提供日常辅助工具。包括老奶奶干饭时间圆形时钟（实时显示当前时间与下次干饭倒计时）、每日任务、活动日历、今日黑暗侵蚀、今日大蜡地图、季节剩余时间、复刻先祖、官方公告等。本站为非官方个人工具，与 Thatgamecompany（TGC）无关联，游戏内信息请以官方为准。

技术说明

本站为纯静态站点，使用原生 HTML / CSS / JavaScript 编写，不依赖任何前端框架与构建工具。公共顶栏、页脚、主题切换等组件统一封装在 components.js 中，修改一处全站生效。

部署方面，源代码托管于 GitHub，通过 Cloudflare Workers 提供全球加速访问。部分第三方 API 通过 Cloudflare Worker 代理以解决跨域问题。所有页面可离线打开，部署简单，维护轻量。

隐私说明

本站不收集任何用户个人数据，不使用 Cookie 追踪，不嵌入广告。主题偏好仅存储在浏览器本地（localStorage），不会上传至任何服务器。第三方 API 的调用由用户浏览器直接发起或通过本站代理转发，本站不记录请求内容。

联系与建议

如果你对本站有任何建议，或发现某个功能失效、数据错误，欢迎通过域名 hean.me 找到这里。每一份反馈都会被认真对待，本站会持续迭代改进。
