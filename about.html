ABOUT · HEAN

站点简介

HEAN 禾安（hean.me）是一个个人站点，也是一块属于自己的网络空间。它从一个简单的聚合搜索页出发，逐步生长出游戏、兴趣、动态等分区，记录学习、体验与生活的碎片。

这里有什么

  • 聚合搜索：首页集成了 Bing、百度、Google 三个搜索引擎，一键切换、即搜即走。
  • 每日一言：每次打开首页，都会从一言接口获取一句随机文字，给页面一点温度。
  • 内容分区：cs2、光遇（天空）、导航、新闻等页面，按兴趣持续填充。
  • 主题切换：顶栏提供暗黑 / 白色双主题，跟随心情切换浏览体验。

技术说明

本站为纯静态站点，使用原生 HTML / CSS / JavaScript 编写，不依赖任何框架与构建工具，资源（图标、背景图）统一存放于 assets/ 目录。所有页面可离线打开，部署简单，维护轻量。
